# Упаковка пакетов (Arch Linux)

Заметки про сборку пакетов для Arch Linux: минимальный пример PKGBUILD
и упаковка Python-пакетов из PyPI.

- [hello-world-pkgbuild](hello-world-pkgbuild/README.md) — минимальный учебный PKGBUILD: один shell-скрипт, сборка через `makepkg -si`.
- [python-pypi-pkgbuild](python-pypi-pkgbuild/README.md) — как достать прямую ссылку на исходники из PyPI и упаковать их в PKGBUILD.
