# Браузеры — Firefox

Настройки Firefox через `about:config` и корпоративные политики. Открыть редактор настроек: ввести `about:config` в адресной строке и подтвердить.

## Вкладки

- `browser.tabs.closeWindowWithLastTab` → `false` — не закрывать окно при закрытии последней вкладки.

## Язык

- `intl.accept_languages` → `ru-RU, ru` — предпочитаемые языки сайтов.

## Интерфейс и клавиатура

- `ui.key.menuAccessKeyFocuses` → `false` — не передавать фокус в меню по нажатию Alt (удобно, когда Alt используется в горячих клавишах).
- `browser.compactmode.show` → `true` — показать компактный режим в «Настройка панели инструментов» → «Плотность».

## Закладки

- `browser.bookmarks.autoExportHTML` → `true` — автоматически выгружать закладки в HTML-файл при выходе.
- `browser.bookmarks.file` — путь к файлу выгрузки (указать свой, например в каталоге профиля или документов).

## Сеть

- `network.http.http3.enabled` → `true` — включить HTTP/3.

## Киоск-режим: доступ только к разрешённым сайтам

Готовый пример политики — в каталоге [firefox-policies/](firefox-policies/): блокируются все сайты, кроме списка исключений, отключается приватный просмотр. Описание формата политик — в документации [policy-templates](https://mozilla.github.io/policy-templates/).
